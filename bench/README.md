# bench/ — experiment harness

This is the harness used for every number in `../REPORT.md`. It was designed for one 8×B200 node split into 8
single-GPU "lanes" (`launch_lanes.sh`). In practice Lambda only had single GPUs, so it ran on **separate single-GPU
boxes** (H100 SXM, GH200, 2× H100 PCIe), each sweeping its own configs one after another against its **own baseline**.
See `../NOTES.md` for the full story.

## Files

| File | Purpose |
|---|---|
| `env.sh` | Shared settings (model path, venvs, default vLLM flags, `BENCH_EXTRA_BODY`, NVRTC / CUDA-compat library paths). Any variable can be overridden from the environment |
| `h100_flags.sh`, `gh200_flags.sh` | **Per-box common vLLM flags actually used** (`--language-model-only`, memory utilization, batch caps). Source after `env.sh` |
| `setup_node.sh` | One-time box setup: CUDA forward-compat (drivers < 580), uv + vLLM 0.33 + FlashInfer kernels, weights, traces |
| `snap_gpus.py` | Polls Lambda's API and auto-launches GPUs as capacity appears (price caps, `--only` shape filter, auto-setup). **Spends money with `--launch`** |
| `make_agentic_trace.py` | Synthetic coding-agent trace (shared prefix + per-session files + multi-turn diffs), sized with the real tokenizer |
| `make_lcb_trace.py` | Newest-N LiveCodeBench problems → prompts + tests |
| `traces/` | **The exact traces used** (byte-identical on every box and endpoint; md5 below) |
| `bench.py` | Streaming client for any OpenAI-compatible endpoint: TTFT, TPOT, per-user and aggregate tok/s; per-run nonce for cache fairness; `--save-outputs` saves reasoning + content |
| `bench_suite.sh` | `short` (sweeps), `full` (final runs), `lcb` (accuracy + grading; `LCB_MAX_TOKENS`, `LCB_TEMPERATURE`, `LCB_TOP_P`) |
| `serve.sh` / `stop.sh` | Start/stop one vLLM server pinned to a GPU; detects startup death |
| `sweep.sh` + `configs/*.sh` | Unattended sweep: serve → bench → scrape `/metrics` → stop; failing configs are logged and skipped |
| `final_box.sh` | Final phase on one box: baseline + final config greedy captures, LCB accuracy, full benchmark |
| `compare_outputs.py` | Offline greedy-equivalence comparison (reasoning + content) between two saved runs |
| `lcb_grade.py` | LiveCodeBench grader (stdin/stdout + functional tests), same grader for every endpoint |
| `analyze_profile.py` | Kernel-time breakdown from a vLLM torch-profiler trace |
| `summarize.py` | Tables + charts; speedups only vs the same box's baseline (`h100_*`, `gh200_*` label prefixes) |
| `collect_results.sh` | Pull results from every box and build one combined report |
| `run_*.sh` | The exact job scripts queued on each box during the run (kept for provenance) |
| `noise_floor.sh`, `launch_lanes.sh`, `fireworks.sh`, `greedy_equiv.py`, `configs/lane*.sh` | From the original 8-lane / Fireworks plan; not used in the final run (kept for reference) |

## Configs actually run

| Box | Config file | What |
|---|---|---|
| H100 SXM | `configs/h100.sh` | baseline, prefix caching, MTP k=3, prefix caching + MTP, baseline repeat |
| H100 SXM | `configs/h100_extra_v2.sh` (generated by `run_extra_h100_v2.sh`) | performance modes, MTP k=2 combo |
| GH200 | `configs/gh200.sh`, `gh200_extra.sh`, `gh200_extra2.sh`, `gh200_post.sh` | MTP depth sweep, combos, big batches, MARLIN / grouped GEMM / -O3, performance modes |
| H100 PCIe ×2 | `run_lcb32k_box.sh`, `run_base32k_now.sh` | LiveCodeBench at a 32k budget, final vs baseline |
| (from H100 node) | `run_or_lcb32k.sh` + `bench_suite.sh … OPENROUTER_API_KEY` | Together via OpenRouter (provider pinned) |

## Reproduce one box

```bash
./setup_node.sh                                   # on a fresh Lambda GPU instance
source h100_flags.sh                              # or gh200_flags.sh
./sweep.sh 0 8000 configs/h100.sh short           # ablation sweep, results in results/<label>/
P=h100 FLAGS=h100_flags.sh FINAL="<flags>" ./final_box.sh   # final phase
python summarize.py --results results             # tables + charts
```

Benchmark any OpenAI-compatible endpoint with the same traces:
```bash
python bench.py --base-url https://openrouter.ai/api/v1 --api-key-env OPENROUTER_API_KEY \
  --model nvidia/nemotron-3.5-super-vl --label provider --trace traces/agentic_short.jsonl \
  --extra-body '{"provider":{"order":["Together"],"allow_fallbacks":false},"chat_template_kwargs":{"enable_thinking":true}}'
```

## Gotchas learned the hard way

- Never overwrite a bash script while it is running (bash reads scripts incrementally); write a new file instead.
- `env.sh` is sourced under `set -e` by some scripts, so it must end with exit status 0.
- vLLM 0.33: `--disable-prefix-caching` (not `--no-enable-prefix-caching`); `--mamba-cache-mode` is a no-op.
- Greedy comparisons must include the reasoning text: with small `max_tokens` the final content is usually empty.
